A radio group picks exactly one of a few options that need a sentence each.

**You provide:** two to five options, each with a label; one is always selected.

- Class `dot-radio` on an `input type="radio"`, wrapped with its text in a `label.dot-opt`.
- Selected is a `text-display` disc inside the ring; unselected is a 1px `text-secondary` ring.
- For two or three one-word options, use a Segmented control. For more than five, use a Select.
